# Ejercicio de Comprensión de Programas

Usando una estrategia de comprensión de programas basada en el **Modelo Oportunista *(De Arriba Hacia Abajo + De Abajo Hacia Arriba)***, determina la funcionalidad del programa `exercise.py`.

## Estrategias para ayudar en la comprensión:

1. Utiliza la información disponible en Internet si no estás seguro sobre alguna construcción del lenguaje Python.
2. Utiliza la IA:
    1. Selecciona en el editor la sección de código que deseas que `GitHub Copilot` te explique.
    2. Teclea `Ctrl+i`.
    3. Introduce el siguiente prompt: `/explain la sección de código seleccionada`.
    4. Da clic en el botón `Ver en Chat` y analiza la respuesta de la IA.

A partir del resultado de tu análisis, completa los siguientes pasos:

1. Identifica los componentes del código: funciones, programa principal, etc.
2. Determina el flujo de control entre las funciones y el programa principal.
3. Determina el flujo de datos entre las funciones y el programa principal (de dónde vienen los datos y a dónde van).
4. Paso a paso, determina el estado del programa usando la tabla adjunta.
5. Concluye el efecto de la ejecución del programa y su relación causa-efecto.
